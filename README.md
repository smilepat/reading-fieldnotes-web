# Reading Fieldnotes — 공개 화면

중국 리딩 교재 1권의 웹 보조 학습자료 (단일 HTML 파일, 설치·로그인 없음).
**이 레포는 공개용 사본입니다.** 원본(원고 데이터·틀·생성 스크립트·검수 기록)은 비공개 레포에 있고, 거기서 만든 파일을 여기에 올려 GitHub Pages 로 엽니다.

- 주소: https://smilepat.github.io/reading-fieldnotes-web/
- 파일: index.html (단원 목록) + 1권 1~10단원 HTML. 검색 엔진에는 보이지 않게 함 (robots.txt, noindex).
- 이 레포의 파일을 직접 고치지 마세요. 원본 레포에서 다시 만든 뒤 덮어씁니다.
